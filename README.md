# Kiwitk Website

A modern medical tourism website with internationalization (i18n) support.

## 🌐 Features

- **Multi-language Support**: 19 languages including English, Chinese, Japanese, Korean, Spanish, French, German, Arabic, and more
- **Responsive Design**: Fully responsive website that works on all devices
- **Modern UI/UX**: Clean and professional design suitable for medical tourism industry
- **Internationalization Ready**: Easy to add more languages and translations

## 📁 Project Structure

```
kiwitk-website/
├── index.html              # Main HTML file
├── css/
│   └── styles.css         # Main stylesheet
├── js/
│   ├── main.js            # Main JavaScript file
│   └── i18n/
│       ├── i18n-core.js   # Internationalization core
│       └── lang/          # Language files
│           ├── en.js       # English
│           ├── zh.js       # Chinese
│           ├── ja.js       # Japanese
│           ├── ko.js       # Korean
│           ├── es.js       # Spanish
│           ├── fr.js       # French
│           ├── de.js       # German
│           ├── ar.js       # Arabic
│           └── ...         # Other languages
└── images/               # Image assets
```

## 🚀 Getting Started

### Prerequisites

- Any modern web browser
- Text editor for development

### Installation

1. Clone the repository
```bash
git clone https://github.com/nuclearton/kiwitk-website.git
```

2. Open `index.html` in your web browser
